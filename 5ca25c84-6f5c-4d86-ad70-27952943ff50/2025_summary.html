2025 年已经结束, 恰逢我从25年年底开始折腾着搭建个人博客, 就以本站第一篇文章回顾一下我在过去的一年里的经历吧.

1. Introduction

时间过得真快啊(总感觉每年都会说这句话), 一转眼 2025 年也画上句号了.

倘若站在 2026 的起点考察一下过去一整年里我的经历, 最先注意到的一定是跟研究生的申请相关, 接下来就是上岸之后的快乐(堕落)生活了(笑). 在政策改革的风口中, 于草台班子行为(也包括自己的)和机缘巧合的见证下, 我在参加的第一个营就拿了 offer 并找到方向比较 match 的导师, 某种意义上算是幸运. 顺利拿到 offer 之后的暑假和大四上学期, 既没什么课程压力也离毕业论文尚远1, 于是就在学业之外2各种折腾, 上手了 Emacs 之后 hacking 不亦乐乎, 玩米家游戏并剪了一点记录向的视频(主要是抽卡记录&主线实况与切片)发在B站3.

前几年分享和记录的欲望越来越淡4, 可能是因为面对升学压力&课业繁忙&周围没什么朋友罢. 但研究生去向确定之后, 身上的压力暂时卸下来, 现实生活中的社交也增加了, 整个人都比过去变得活泼了不少, 渐渐比以往更希望留下自己的痕迹. 借此跨年之际, 请以 2025 年度回顾作为 Blog 的第一篇文章, 重新开始记录自己的想法和经历吧.

2. 申请经历

一句话总结: 没有太多波折就获得了一个让自己满意的结果. 但还是简单记录一下发生了什么, 涉及的时间跨度大致从五月中下旬到七月初.

2.1. 25年的变化

2025 年恰逢保研形势和出国形势双重变化:

  • 保研方面, 据说未来夏令营要被砍, 不过25年很多都还在. 但至少25年各院所下发通知的时间, 交通住宿安排, 夏令营的效力乃至举办与否等方面, 大都和往年有所不同;
  • 貌似国外 phd 申请形式不好5. 我还记得之前 Harvard 好像还闹过一些有关留学生的事情.

最终的结果就是22级保研er不仅要面对不同于往年且在开营时间, 优营效力等方面存在不确定性的夏令营情况, 也要与部分出国er竞争优营名额.

还好25年应当算是过渡期, 往年经验还能派上用场, 据说到26年就和既往完全不一样了. 以及北京几个院所的夏令营基本都错开了, 顺便科大上交等的夏令营截止报名的时间基本在北京几个院所开营之后. 这让我不用在已经报了的几个北京的院所之间做选择(其实只报了2个). 可惜我因为各种原因, 包括但不限于认为夏令营时间会撞在一起, 报名的时候折腾文书到不想弄了, 没多报几个院所(理论所, 卡所, etc.). 虽然不一定能入营or优营, 但没能去看看确实可惜. 除此之外, 也能根据前面的面试结果确定要不要再报北京之外的院所, 一方面是北京就有我想去的院所, 有选择的话不想去南方; 另一方面是上交不包住宿还得和同学订酒店. 怪折腾的.

2.2. 奇妙の经历6

Sec.1中提过草台班子行为(笑), 一时间能想起来的有:

  • 有的院所的夏令营通知就一张海报, 里面的报名链接没法复制;
  • 有的院所提交夏令营报名信息填 excel 表格发邮箱;
  • 有的院所面试完之后彻底没消息大概一周后才给正式通知7.
  • 我自己踩着 ddl 交材料, 以及因为各种原因有个夏令营的推荐信交晚了, 只能给对应的负责老师打电话. 还好最后还是入营了.
  • 我自己上午去参营的路上现用 deepseek 翻译自己的 PS, 用来准备下午的面试.

还有机缘巧合. 为什么这么说呢, 因为我最终联系的研究生导师是参营过程中作报告的老师, ta 当时不在官网上招生列表中. 当时拿到参营结果之后问之前联系过的老师得知 ta 已经找到心仪的学生了, 后来辗转确认现在的导师招生且获得了联系方式, 线上聊了一下之后顺利拿到 offer.

2.3. 一点想法

其实再次面临"为了升学而努力"这种情景, 我有点想起三年前(22年)的高考. 在当时(也可能是当下)的我的心里, 看待研究生申请这件事有几分弥补高考遗憾的感觉, 大概是面临相似的情景时有点触景生情. 不过也就到此为止了. 从头到尾其实也没有太多情绪上的不安啊起伏啊什么的, 可能是过程相对顺利吧.

3. 更好的PC8

有关PC的折腾经历着实值得我大书特书, 因为这几乎是我下半年干得最多的事了. 25年6月底开始用 WSL 并接触 Git, 虽然一开始只是把一些东西整理起来放在 GitHub 上; 大概8月份中下旬开始写 Dockerfile 做 texlive 的 docker 镜像, 同时也真正有了版本管理的需求; 之后开始用 Emacs, 一开始是为了用 org-roam 搭建知识网络, 后来心血来潮买了几个域名就基于 ox-publish 搭了这个 Blog.

3.1. 动力

在最开始, 其实是完全的实用需求驱动, 到后来就是兴趣驱动了. 大概是25年6月份, 面对电脑谜之清理不出来的存储空间, 我索性直接重置, 同时因为 LaTeX 在 Windows 里编译速度感人, 遂在重置后把 texlive 安装在 WSL9 里, 成果显著. 面对将来不可避免的重新配环境的问题10, 我在简单调研之后选择拥抱 Docker, 于是在 AI 的帮助下开始搓 Dockerfile, 顺便学着用 Git.

9月份开学之后, 因为要整理笔记, 期待组织成某种意义上的知识网络, 遂于知乎调研最后选择了基于 org-roam 实践 Zettelkasten 笔记法的方案, 由此开始使用 Emacs, 东凑西凑攒了一份配置就开始用了. 并根据自己的实际情况(比如物理学知识成体系较多, 碎片化的点相对少)做了一些目录结构和实践方法方面的适应性调整, 也相应的写了一些 elisp 函数.

3.2. As an Emacser based on LLM

一入 Emacs 门深似海(误), 从 Emacs 开始, 我折腾电脑就逐步转向兴趣驱动. 当时上手的时候确实没想到, 这个学期做的最多的事情是写 Emacs 配置文件. 整个过程中还踩了不少坑, 包括但不限于被AI幻觉欺骗, 自己造完轮子之后发现 Emacs 原生有相关支持等.

必须承认, vibe coding 太爽了, 一方面大大降低入门的门槛; 另一方面比如使用 VSCode 插件, 可以直接读取本地文件, 极大的减少了来回复制粘贴的麻烦. 为了尽量规避 AI 的缺点, 我的措施是首先讨论确定需求于目的, 然后自己扒源码 or 查资料提供给 ta, 并且仔细检查 AI 给出的代码中用到的API和函数并逐步测试.

3.3. "成果"

截至目前, 勉强称得上成果的主要有两项:

  • 我称之为 org-roam-organize , 其实就是写了几个函数主要基于查询 org-roam.db 提供几个方便管理 org-roam node 的功能, 在使用端主要是几个以 id-type link 收集指定 tag 类型 node 的 .org 文件;
  • 个人博客网站, 托管在 GitHub Pages 上, 网页使用纯 html+CSS, 以 .org 文件作为源用 ox-publish 导出, 样式文件和部分 elisp 函数都参考了 Eli's Blog.

4. 有关学习

上半年就是普普通通的上课学习. 拿到 offer 之后我本来想得可好了, 什么暑假把需要的和感兴趣的数学看看学一学, 开学之后修读一下"憧憬已久"的专业选修课, 其他时间读读论文, 其实几乎一样也没干成. 具体表现为暑假只看了三节范畴论入门的内容11, 开学之后选了粒子物理和规范场论也没认真学, 前者马上就得突击期末考试, 后者期中退课了. 至于读论文这件事, 还好有组会鞭策我, 从25年8月份到现在算是学了一点点拓扑和任意子的东西12, 好歹现在被问到这些概念时, 不至于一问三不知了.

5. 有关娱乐

2025年我玩游戏玩的更多了, 看小说可能不如往年多. 本节的重点会放在游戏, 毕竟是年度总结, 而我实在是看网文看小说太多, 以至于今年没什么好单独拿出来说的, 之后会单独出一篇文聊聊小说13, 也会解释下面不加解释提到的一些观点和评价原则. 考据太费精力, 我更多时候还是随缘体验游戏, 有时会出现游戏的细节我没注意到, 所以也就是聊点自己的主观看法.

5.1. 25年玩了什么

游戏方面, 自从24年7月入坑 ZZZ(绝区零) 就一直玩到现在(蘸豆爽!); 原神玩了三年虽然有点倦了, 但是也没弃坑; 暑假期间被翁法罗斯的故事吸引入坑了崩铁(崩坏: 星穹铁道), 这下成为原铁绝三修玩家了. 思来想去, 最有兴趣说点啥的还是崩铁, 不过也不会冷落又陪了我一年的原神和 ZZZ, 突出一个端水(笑).

5.2. 崩铁

先说说崩铁本身. 虽然已经算是玩了半年, 我到现在还是把崩铁当作一部42天更番剧来看, 包括抽卡在内的其他玩法对我来说都是点缀, 所以在能打通剧情之后就不太在意强度方面的问题了. 在当前, 在剧情和世界观方面, 我会给予崩铁比原神和绝区零更高的评价. 银河足够宽广, 可以容纳更多不同, 相比而言原神和绝区零的世界观稍显狭窄, 很多元素放在后两者里即使给予合理的解释也会让我感到突兀, 而在崩铁中这一点相对更好处理. 此外, 崩铁中的世界观解密很大一部分借助模拟宇宙系列玩法逐步推进, 我个人感觉上相比原和绝更集中一些, 而且形式上更"现代"更像是正式的科学研究. 崩铁虽然只实机上线了几个世界, 但却通过故事和各种文本勾勒出一个宏大的世界观, 让玩家愿意相信在当下的足迹和视线之外还有无穷的远方. 这种在逻辑上自洽(至少一眼看上去如此), 宏大且细节丰满的世界观真的很吸引我.

再说说翁法罗斯. 其实很多别人眼中的痛点其实对我来说可能无关紧要或者说是优点, 比如新名词, 新设定, 古希腊风格的人名, 隐喻, 史诗化的表述等, 还有站桩对话什么的. 可能因为我还是用读书的眼光去评价吧. 我个人觉得长线运营游戏的形式在某种程度上拖累了这个故事的主线, 比如版本之间的相对独立, 伏笔埋得太远以至于忘记, 人物登场受到多方资源限制等. 当然, 游戏的形式也带来纯文本阅读无法比拟的视听享受, 在某些地方表达起来更自由方便, 传递信息的手段也更加丰富. 只能说是成也萧何"败"也萧何了.

翁法罗斯的故事本身是一部壮丽的史诗, 我见到成长, 奉献, 牺牲, 坚持, 反抗, 直到三千万世的徒劳最终结出果实. 作为开拓的一站, 翁法罗斯的开拓之旅是"我"踏上开拓的道途以来首次以如此深刻的方式参与一个世界的历史进程. 在这个意义上, "我"在翁法罗斯的旅程实践了在匹诺康尼从米哈伊尔那一批老无名客身上继承的精神. 而放在整个主线剧情中, 更多的世界观解密通过翁法罗斯或显或隐地推进, 前者是明面上通过翁法罗斯作为"三重命途交织之地"给出的有关情报, 后者可能通过对各命途的模拟来暗示某些真相(虽然并无证据).

5.3. 原神

有关原神其实没什么好说的, 我现在真的算是处于半退坑的状态了, 具体表现为地图也懒得探索, 世界任务也没怎么做, 有时候深渊都忘打, 纠缠之缘囤了好几百抽随眼缘抽卡. 因为我还算比较喜欢原神的故事, 所以也一直跟着玩, 不过其实也没什么激情. 好吧, 其实这是我玩游戏的平常状态来着, 所以倒也正常. 顺便原神的剧情编排和演出还是功力在线, 不说多么多么好吧, 但绝对不算差. 虽然纳塔版本我现在回忆起来说没太多记忆点, 可能是有点审美疲劳了, 也可能是心里清楚最后必然胜利, 所以对剧情没有期待了. 但挪德卡莱从玩法到故事都让我耳目一新, 重新找回了旅行的意义(笑).

5.4. ZZZ

有关 ZZZ. 说真的, 现在继续玩的动力可能就是战斗爽, 以及作为开服玩家期待未来 ZZZ 做的更好. 我还记得入坑是因为看到狼哥的角色展示觉得真帅啊, 开始玩之后发现还有很多惊喜. 都市风日常风非常有代入感, 无论是录像店的经营, 六分街的店铺, 还是绳网的委托和帖子, 就像真的生活在新艾利都一样; 主角明面上作为录像店主, 暗地里作为传奇绳匠, 常年生活在社会灰色区域必然历练出对应的性格特质和处事方法; 还有后末日时代下, 代理人经常需要进出空洞, 徘徊在生死边缘, 新艾利都表面平静, 暗地里云谲波诡, 这样的故事背景下人与人之间的关系, 情感, 必然不同于和平年代, 那一定是更加肆意的, 会有人性的光辉和阴暗交织在一起, 希望和绝望此起彼伏. 总而言之, 至少刚入坑 ZZZ 的我着实被这些元素惊艳到了. 至于剧情方面, 对于开服的几个版本我会说它还算不错, 漫画式的演出也很有特色, 人物形象也很鲜明.

实话说, 最开始玩的详细感受已经记不太清楚了, 毕竟已经过去一年多, 而且很可能存在我潜意识中的美化, 毕竟后来的剧情体验我说实话有点无力吐槽. 对于砍掉走格子, 我很难说它到底是好是坏, 但对于绳匠亲身下空洞这件事, 包括有关的剧情, 我一直颇有微词. 在我的第一观感里, 这意味着:

  • 主角从幕后走到台前, 剧情体验上失去了纵观全局的视角, 同时也导致玩家体验中法厄同兄妹对剧情的贡献非常容易失去平衡;
  • 作为空洞中几乎无作战能力的人员, 主角必然不如伊埃斯作为邦布容易被保护和维护, 甚至有的剧情推动是通过代理人救主角而付出代价实现的;
  • 主角突然出现的奇异能力, 虽说客观上前后有一定的解释, 但是主观给我的感觉就是机械降神.

第二季的故事就游玩体验上, 前三章还行, 从第四章开始一言难尽. 第四章伊德海莉的能力出现的没有铺垫, 像是为了推动主线才设计的; 白真斗和真斗的对打知其燃不知其所以燃; 只有卢西娅那一段, 情绪是悲伤的, 叙事是收敛的, 反而带来一种哀而不伤的感觉, 在一众直白的悲惨经历里显得格外突出. 第五章也有说不出的别扭感, 琉音的坚持找不到根基在哪里, 般岳过去所谓的"罪"分量在后末日的背景中相较于前面的铺垫而言是否有些太轻了.14

但话又说回来, 这些缺点客观上也能理解, 毕竟砍掉走格子应当是伤筋动骨, 而绝区零还要维持每个版本2位限定S级代理人的更新, 还在不断对系统和玩法做优化, 等等, 可能也分不出太多精力仔细打磨剧情罢. 另外剧情之外的部分, 比如战斗, 美术, 音乐, 日常减负, 代理人邀约等至少在我看来还算不错. 没想到前面会絮絮叨叨说那么多, 主要是最近恰逢绝区零版本更新, 2026-01-03 刚过了新剧情有些事情不吐不快. 总之, 希望绝区零变得更好.

6. 其他日常

暑假跑到市区玩&见网友. 学期内跟朋友们出去吃了 N 顿饭, 玩了 N 次, 再加上网购了不少电子设备和吃的, 这学期的月支出也目测在 2000++(悲). 虽然往年稍稍攒下来一点点钱, 不至于整天向家里要钱, 但还是有些惭愧.

在前面提到的折腾经历和游戏游玩与录屏剪辑过程中, 我充分感受到现在这台电脑15的性能瓶颈, 最直观的就是常有内存占用 90%+, 以及游戏和录屏卡顿了. 于是理所当然的想换一台电脑, 到处瞅了半天最后还是眼馋 Intel 画的 Panther Lake 大饼一直等到现在16. 谁能想到直接碰上内存硬盘大涨价, 只能希望26年我看好的核显全能本不会太超预算了.

7. Conclusion

没想到一份年度总结写了三四天, 好几千字. 不管如何, 2025 年就这样过去了, 对我来说更重要的事情不是一分不差的记录生活的细节, 而是往前看, 向前走(才不是因为我现在要去做一份 Slides 没工夫仔细推敲了).

你好, 2026.
